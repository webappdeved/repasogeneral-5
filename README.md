## Descripción del Proyecto
Esta suite de desarrollo consolida los pilares de bajo nivel abordados en la materia: recursividad con control de caso base, búsqueda secuencial lineal \(O(n)\) en memoria contigua y manipulación de punteros para el intercambio físico de variables.
